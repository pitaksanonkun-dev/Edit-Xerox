MacCollector.exe – เก็บชื่อเครื่อง + MAC Address เป็นไฟล์ JSON สำหรับ Xerox Host DNS Bridge
=========================================================================================

ใช้ทำอะไร
  เก็บข้อมูลของเครื่อง PC ปลายทาง Scan แล้วนำไฟล์ไปกด "นำเข้าไฟล์ JSON" ในหน้าเพิ่ม Host ของ ESP32
  ระบบจะกรอก ชื่อเครื่อง, MAC Address, IPv4/IPv6 สำรอง, ชื่อแฝง, พอร์ต Relay และหมายเหตุ ให้อัตโนมัติ

วิธีใช้
  1. คัดลอก MacCollector.exe ไปที่เครื่อง PC (หรือเปิดจาก Flash drive / Shared folder) แล้วดับเบิลคลิก
     - ไม่ต้องติดตั้ง ไม่ต้องเป็น Admin (ใช้ .NET Framework 4 ที่มากับ Windows 10/11)
  2. การ์ด "การ์ดแลนที่เชื่อมต่ออยู่" (ซ้าย) – โปรแกรมเลือกการ์ดที่มี Gateway / สาย LAN ให้ก่อน
     คลิกการ์ดอื่นได้ถ้าต้องการใช้ตัวนั้น · การ์ด "เครื่องนี้" แสดงชื่อเครื่อง / MAC และสถานะ "พร้อม Export"
  3. ตรวจ/แก้ข้อมูลในช่อง "ข้อมูลที่จะ Export" (ต้องมี ชื่อเครื่อง และ MAC อย่างน้อย)
     ใส่ ชื่อแฝง หรือ พอร์ต Relay เพิ่มได้ – ดูผลได้ทันทีที่ "ตัวอย่างไฟล์ JSON"
  4. เลือกที่เก็บไฟล์: "เลือกโฟลเดอร์…" (เช่น Flash drive หรือ Shared folder) แล้วกด "Export ไฟล์ JSON"
     หรือ "บันทึกเป็น…" เพื่อเลือกตำแหน่งและชื่อไฟล์เอง / "คัดลอก JSON" เพื่อวางที่อื่น
     (โปรแกรมจำโฟลเดอร์ล่าสุดไว้ให้ครั้งถัดไป)
  5. ในหน้า ESP32 → เครื่องปลายทาง Scan → + เพิ่ม Host → นำเข้าไฟล์ JSON → เลือกไฟล์ → บันทึก

เก็บหลายเครื่องพร้อมกันแบบไม่มีหน้าต่าง (Login script / GPO)
  MacCollector.exe -OutDir \\server\share\macs -Quiet
  → ได้ไฟล์ <ชื่อเครื่อง>.json ในโฟลเดอร์นั้น (exit code 0 = สำเร็จ, 2 = ไม่พบการ์ดแลน)

รูปแบบไฟล์ (ชื่อฟิลด์ตรงกับช่องในหน้าเพิ่ม Host)
  {
    "type": "xerox-host-dns-host",
    "name": "PC-ACC01",
    "mac": "A4:BB:6D:12:34:56",
    "aliases": "scan-acc",            (ถ้ากรอก)
    "fallback4": "192.168.20.86",
    "fallback6": "fd00:20::86",
    "note": "Ethernet | user: CORP\somchai | domain: corp.local",
    "relayPort": 4451,                (ถ้ากรอก)
    "adapters": [ ...การ์ดแลนทั้งหมดของเครื่อง (ข้อมูลประกอบ)... ]
  }

หมายเหตุ
  - Wi-Fi ที่เปิด "Random hardware addresses" จะเปลี่ยน MAC ได้ – โปรแกรมจะเตือน ควรปิด หรือใช้สาย LAN
  - การ์ด VPN / Hyper-V / VMware จะไม่แสดง (แสดงเฉพาะการ์ดจริง)

ซอร์สโค้ด: src\*.cs   สร้าง exe ใหม่: src\build.bat (ไอคอนวาดจากโค้ดใน Ui.cs → src\app.ico)
