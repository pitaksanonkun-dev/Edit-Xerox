SMB Port Tester v1.0  (Xerox Host DNS Bridge)
=============================================

ใช้ทดสอบว่าเครื่อง Xerox ส่ง Scan แบบ SMB ไปยังพอร์ตอื่นนอกจาก 445 (เช่น 4451) ได้หรือไม่
โดยยังไม่ต้องใช้ ESP32 และกดคืนค่ากลับให้เหลือเฉพาะ SMB 445 ได้ในคลิกเดียว

วิธีใช้
------
1. ดับเบิลคลิก SmbPortTester.exe แล้วกด Yes ที่หน้าต่าง UAC (โปรแกรมต้องใช้สิทธิ์ Administrator)
2. พอร์ตที่ต้องการเปิด      : 4451   (หลายพอร์ต 4451,4452 หรือเป็นช่วง 4451-4460)
   IP เครื่องผู้ส่ง (Xerox)  : 192.168.20.109   (คั่นด้วย , หรือใส่เป็นวง 192.168.20.0/24)
3. กด "เปิดพอร์ต" แล้วดูบันทึกการทำงาน ต้องขึ้น ✓ "SMB ของเครื่องนี้ตอบกลับ"
4. ที่เครื่อง Xerox ให้ตั้ง IP Address และ Port ตามกล่องสีฟ้า (เช่น 192.168.20.72 : 4451)
   ใส่ Share, Login และ Password ให้เหมือนที่ทดสอบผ่านกับพอร์ต 445 แล้วกด Destination Test
5. ทดสอบเสร็จแล้วกด "ปิดพอร์ตและคืนค่า"

สิ่งที่โปรแกรมทำเมื่อกด "เปิดพอร์ต"
--------------------------------
- netsh interface portproxy : 0.0.0.0:<พอร์ต> → 127.0.0.1:445
- เปิดบริการ IP Helper (iphlpsvc) ถ้ายังไม่ทำงาน เพราะ portproxy ต้องใช้บริการนี้
- Windows Firewall : สร้างกฎ "SMB Port Tester" ที่อนุญาตเฉพาะ IP ผู้ส่งที่กำหนด
  และเฉพาะเครือข่าย Domain/Private
- ลบกฎเดิม "Allow SMB 4451" ที่สคริปต์ .bat สร้างไว้ เพราะกฎนั้นเปิดให้ทุก IP
- Registry (ถ้าเลือก) : DisableStrictNameChecking / DisableLoopbackCheck
  ค่าเดิมจะถูกบันทึกไว้ที่ C:\ProgramData\SmbPortTester\state.txt เพื่อใช้คืนค่า

สิ่งที่โปรแกรมทำเมื่อกด "ปิดพอร์ตและคืนค่า"
---------------------------------------
- ลบ portproxy ทุกรายการที่ส่งต่อไปยัง 127.0.0.1:445
- ลบกฎ Firewall "SMB Port Tester" และ "Allow SMB 4451"
- คืนค่า Registry เป็นค่าก่อนการทดสอบครั้งแรก
  ถ้าไม่พบค่าเดิมที่บันทึกไว้ จะลบค่าที่สคริปต์ .bat ตั้งไว้ ให้กลับเป็นค่าเริ่มต้นของ Windows
- SMB 445 ของ Windows ไม่ถูกแตะต้อง

การอ่านผล Destination Test ของ Xerox
-----------------------------------
- 4451 ไม่ผ่าน "Cannot Login" และแผงสถานะขึ้นว่าประเภทเครือข่ายเป็น "Public"
  → กฎ Firewall แบบ Domain/Private ใช้ไม่ได้บนเครือข่าย Public ทำให้ Xerox ถูกบล็อก
     ให้กด "เปิดพอร์ต" แล้วเลือกอย่างใดอย่างหนึ่ง
     - Yes : เปลี่ยนเครือข่ายเป็น Private (โปรแกรมจะคืนเป็น Public ให้เมื่อกดคืนค่า)
     - No  : เปิดกฎใน Public ด้วย (ยังจำกัดเฉพาะ IP ผู้ส่ง)
- 445 ผ่าน แต่ 4451 ไม่ผ่าน "Cannot Login" และสถานะในโปรแกรมแสดงว่าไม่มีพอร์ตทดสอบเปิดอยู่
  → ยังไม่ได้เปิดพอร์ต ให้กด "เปิดพอร์ต" ก่อน
- เปิดพอร์ตแล้ว ปุ่ม "ทดสอบ SMB" ผ่าน แต่ Xerox ยังขึ้น "Cannot Login"
  → ตรวจว่าใส่ Password ใหม่ในหน้าแก้ไขรายการ Xerox แล้ว
     (ถ้าเว้นว่างไว้ Xerox อาจทดสอบด้วยรหัสว่าง)
  → ถ้ายังไม่ผ่าน ให้เปิดตัวเลือก DisableLoopbackCheck แล้วรีสตาร์ทเครื่องและทดสอบใหม่
     ทดสอบเสร็จแล้วต้องกดคืนค่าทันที
- 4451 ผ่านทั้ง 3 ขั้น (Destination / File Write / File Remove)
  → Xerox รองรับพอร์ตอื่นนอกจาก 445 จึงใช้โหมด Relay ของ ESP32 (1 พอร์ตต่อ 1 PC) ได้

ข้อควรระวัง
-----------
- ใช้สำหรับทดสอบเท่านั้น เมื่อใช้งาน ESP32 จริง เครื่อง PC ไม่ต้องเปิดพอร์ตเพิ่ม
  เพราะ ESP32 เป็นฝ่ายรับที่พอร์ต 4451 แล้วส่งต่อไปยังพอร์ต 445 ของ PC เอง
- ปุ่ม "ทดสอบ SMB" ทดสอบภายในเครื่องเท่านั้น ไม่ได้ผ่าน Firewall
  การทดสอบจริงต้องกด Destination Test ที่เครื่อง Xerox

สร้างใหม่จากซอร์ส : src\build.bat  (ใช้ .NET Framework 4 ที่มีอยู่ใน Windows 10/11)
