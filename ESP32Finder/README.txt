ESP32 Finder v1.0  (Xerox Host DNS Bridge)
==========================================

ค้นหาว่าบอร์ด ESP32-ETH01 (Xerox Host DNS Bridge) ใช้ IP อะไรอยู่
ใช้ได้ทั้งตอนที่บอร์ดรับ IP จาก DHCP และตอนตั้ง Static IP ไม่ต้องติดตั้งโปรแกรม ไม่ต้องใช้สิทธิ์ Administrator

วิธีใช้
------
1. ดับเบิลคลิก ESP32Finder.exe โปรแกรมจะค้นหาให้ทันที (ประมาณ 3–6 วินาทีต่อวง /24)
2. การ์ดที่พบจะแสดง IP ตัวใหญ่ ให้ดับเบิลคลิกการ์ดหรือกด "เปิดหน้าเว็บ"
   หรือกด "คัดลอก IP"
3. ถ้า ESP32 อยู่คนละวงกับเครื่องนี้ ให้ใส่ "วงเพิ่มเติม" แล้วกด "ค้นหา ESP32"
   ใส่ได้หลายแบบ เช่น 192.168.30.0/24, 192.168.30.10-60 หรือ IP เดียว
   คั่นด้วย , ได้หลายวง

วิธีที่โปรแกรมใช้ค้นหา
-------------------
- ลอง IP ล่าสุดที่เคยพบก่อน และลองชื่อ "xerox-dns" ที่บอร์ดแจ้งไว้กับ Router ตอนรับ DHCP
- กวาดพอร์ต 80 ทุก IP ในวง LAN ของเครื่องนี้ แล้วดูหน้าล็อกอินของเว็บ
  บอร์ดจะตอบว่า realm="Xerox Host DNS" จึงระบุได้โดยไม่ต้องล็อกอินและไม่ต้องแก้โปรแกรมในบอร์ด
- อ่าน MAC Address จาก ARP (เฉพาะวงเดียวกัน) ใช้จำบอร์ดแต่ละตัว
  ถ้าครั้งนี้ IP ต่างจากครั้งก่อน การ์ดจะแจ้ง "IP เปลี่ยนจากครั้งก่อน"
- ถ้าติ๊ก "อ่านรายละเอียด" และใส่ชื่อผู้ใช้/รหัสผ่านหน้าเว็บ ESP32 จะแสดงเวอร์ชัน, DHCP/Static,
  ความเร็ว LAN, เวลาที่เปิดเครื่องมาแล้ว และจำนวน Host
  (โปรแกรมเก็บเฉพาะชื่อผู้ใช้ ไม่เก็บรหัสผ่าน)

ข้อมูลที่โปรแกรมบันทึกไว้
----------------------
%AppData%\ESP32Finder\settings.txt   วงเพิ่มเติม, ชื่อผู้ใช้, ตัวเลือกอ่านรายละเอียด
%AppData%\ESP32Finder\known.txt      MAC → IP ล่าสุดของบอร์ดที่เคยพบ

ถ้าไม่พบ
-------
- รอประมาณ 20 วินาทีหลังเปิดไฟบอร์ด (ถ้าสาย LAN ลด Link เหลือ 10 Mbps จะใช้เวลานานขึ้น)
- ตรวจว่าเครื่องนี้อยู่วงเดียวกับบอร์ด หรือใส่วงของบอร์ดใน "วงเพิ่มเติม"
- Firewall หรือ VLAN ที่กั้นพอร์ต 80 ระหว่างวงจะทำให้ค้นหาไม่เจอ

สร้างใหม่จากซอร์ส: src\build.bat
