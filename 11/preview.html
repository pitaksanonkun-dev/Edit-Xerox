      รับ IP อัตโนมัติ (DHCP)
      IP ของ ESP32 ต้องคงที่ เพราะเครื่อง Xerox ส่งงานมาที่ IP นี้ (Relay) หรือถาม DNS ที่ IP นี้ · เลือกได้ 2 แบบ: ตั้ง Static IP ที่นี่ หรือเปิด DHCP ไว้แล้วจอง IP ใน Router (แนะนำถ้า Switch เปิด DHCP Snooping / Dynamic ARP Inspection)
      ถ้าย้ายไปเสียบวงอื่น ให้ใช้ DHCP แทนชั่วคราว (แนะนำ) – ทุกครั้งที่เสียบสาย ESP32 ตรวจว่ามี Gateway หรืออุปกรณ์ในวงของ Static IP ตอบภายใน 90 วินาที ถ้าไม่มีจะใช้ DHCP จนกว่าจะรีบูต (ค่า Static ยังเก็บไว้) แล้วเปิดหน้าเว็บได้ที่ http://ชื่ออุปกรณ์/ หรือ ESP32Finder
      กรอกเอง: IP ที่ว่างในวงนี้ และอยู่นอกช่วงที่ Router แจก DHCP
      แนะนำให้ใส่: ใช้ซิงก์เวลา (NTP) ให้ Log และเป็น DNS ต้นทางเมื่อช่อง Upstream DNS ว่าง · ใส่ DNS เดียวกับเครื่อง PC ในสำนักงาน (DNS ของ AD / Router) · ห้ามใส่ IP ของ ESP32 เอง
      เปิดหน้าเว็บด้วยชื่อได้โดยไม่ต้องรู้ IP: http://ชื่อนี้/ หรือ http://ชื่อนี้.local/ (PC ในวง LAN เดียวกัน) · ใช้ a-z 0-9 - ไม่เกิน 15 ตัว

      DNS Server

      ควรเป็น DNS เดิมของบริษัท เช่น Domain Controller
      จับคู่ชื่อแม้มีโดเมนต่อท้าย เช่น PC01.xxx.yyy → PC01
      ตอบ IPv6 (AAAA record)
      ให้บริการเฉพาะเครื่องพิมพ์ที่อยู่ในรายการเท่านั้น

      การค้นหา IP ของ Host

      1800 = ทุก 30 นาที (แนะนำ) · 3600 = ชั่วโมงละครั้ง · ค่าน้อยทำให้มีแพ็กเก็ตค้นหาในเครือข่ายบ่อยขึ้น
      ค้นหา IP เมื่อ Xerox ส่งงานเท่านั้น (แนะนำ) – ถ้าไม่ได้ยืนยัน IP ของ PC ภายใน 2 นาที จะถามก่อนส่งต่อ (ช้าลงประมาณ 1 วินาทีเฉพาะการเชื่อมต่อแรกของงาน) และไม่สแกนเครือข่ายตามรอบ
      NetBIOS Name Service (UDP 137)
      LLMNR (UDP 5355) – รองรับ IPv4/IPv6
      mDNS (UDP 5353, ชื่อ.local) – รองรับ IPv4/IPv6
      ดักฟังการประกาศชื่อ (รู้ IP ใหม่ทันทีที่เครื่องเปิด)

      เครื่องปลายทางที่อยู่ต่างวง LAN (ต่าง Subnet / VLAN)

      Broadcast/multicast ข้าม router ไม่ได้ ใช้ 2 วิธีนี้แทน (Relay ส่งข้ามวงได้ถ้า router อนุญาตให้ ESP32 เข้าถึงพอร์ต 445 ของวงนั้น)
      ส่งคำถามแบบ unicast ไปทุก IP ในวงนั้นทุกรอบ (/22–/30) – Firewall ของ PC ต้องอนุญาต UDP 137 จากวงของ ESP32
      ถาม DNS ของบริษัท (Active Directory) ด้วยชื่อ Host + Domain suffix ด้านบน
      เหมาะกับเครื่องที่ join domain และลงทะเบียน DNS อัตโนมัติ ต้องกรอก Upstream DNS เป็น DNS ของ AD และ Domain suffix
