ตัวอย่างหน้าเว็บ Xerox Host DNS Bridge (ไม่ต้องมีบอร์ด ESP32)
================================================================

วิธีเปิด : ดับเบิลคลิก preview.html (เปิดด้วย Chrome / Edge ได้เลย ไม่ต้องติดตั้งอะไร)

- หน้าตาและการทำงานเหมือนหน้าเว็บที่อยู่ใน ESP32 ทุกอย่าง (สร้างจาก XeroxHostDNS\WebPage.h ไฟล์เดียวกัน)
- ใช้ข้อมูลจำลอง: PC 5 เครื่อง, Xerox 3 เครื่อง, มีงาน Scan วิ่งผ่าน Relay และ PC-HR01 จะเปลี่ยน IP ให้ดูหลังเปิดหน้า ~25 วินาที
- กดเพิ่ม / แก้ไข / ลบ Host และเครื่องพิมพ์, ทดสอบชื่อ, บันทึกการตั้งค่า, ดาวน์โหลด Backup ได้จริง
  (ข้อมูลอยู่ในหน้านั้นเท่านั้น รีเฟรชแล้วจะกลับเป็นค่าตัวอย่าง)
- การตรวจสอบข้อมูล (ชื่อซ้ำ, พอร์ตซ้ำ, Relay เกิน 6 Host, IP ผิดรูปแบบ) ทำงานเหมือนในเฟิร์มแวร์

ไฟล์ในโฟลเดอร์นี้
- preview.html       หน้าตัวอย่าง (เปิดไฟล์นี้)
- mock.js            ตัวจำลอง API ของ ESP32 + ข้อมูลตัวอย่าง
- build-preview.js   สร้าง preview.html ใหม่หลังแก้ WebPage.h :  node build-preview.js
